Tesserae Sortis

This page is a motif test — pure CSS, no image assets. The tesserae show up in the header band above, the rule under each heading, the divider below, and the list tiles — while the reading surface itself stays calm and legible. Nothing busy sits behind body text.

How the mosaic is spent

  • Header band — busy is fine here; no text reads through it.
  • Heading rules — a short tessera strip instead of a plain line.
  • Section dividers — a full tessera rule between blocks.
  • List markers — a single tilted tile.
