## Core engine

OK [Engine] A roll means there is something interesting to see; the dice say how much (Lee, S13, the watcher). The GM needn't know the answer in advance -- let the dice write it, or merely hint. -> gm-rules.md: one line in the "when to roll" guidance.

OK [Engine] Effect is measured against the opposition's LEVEL, not its pool (Lee, S13). A pool includes skill, so Level <= pool: 4 dice means Level 4 only if untrained. Effect equal to Level = a good read with the finest detail held back; effect over Level = complete. -> core-mechanics.md / resolving-combat.md: state it where effect is defined. Used all session; worked every time.

OK [Engine] Social attrition (Lee, S13, the chapter's doubt). A room's doubt as an attrition track (rating 4); Cari's effect accumulates across rolls; the room is won when the total passes the rating. "Practically anything can be handled that way." -> accumulated-progress.md: a social example.

OK [Engine] Learned fear as an attrition track (S13, Benno). The long physical work (a contracture) is accumulated progress with no time pressure -> no nightly rolls; the night's contest was the leg's LEARNED FEAR, rating 3, cleared when the total passed it. Splitting "the long cure" from "tonight's contest" played cleanly.
