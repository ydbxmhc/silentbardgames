# Glossary

**Boost** Temporary modifier adding to future EL. **Contingent** Secondary action that only occurs if primary succeeds. **Dedicated** Wagered points assigned to specific outcome type. **Effect** Successful result after opposition subtracted. What actually happens. **EL (Effective Level)** Total capability for specific action. Sum of Level + relevant Roles, Maneuvers, Modifiers. **Level** Character's base capability and durability. Foundation for all rolls. **Maneuver** Specialization within a Role. Adds rank to EL when applicable. **Modifier** Bonus or penalty to EL (circumstance, gear, conditions, Boosts). **Opposition** A roll against action that can generate effect. Both sides roll; higher wins, affects loser. **Persistent** Effect lasting beyond immediate action (typically full scene). **Resistance** A roll resisting action that only prevents effect. Generates no effect of its own. **Result** Number generated by roll. **Role** Broad thematic competency (Warrior, Healer, etc). Adds rank to EL when applicable. **Roll** Generate number via dice. Must be >0 and ≤ EL to succeed. **Split** Dividing EL among multiple simultaneous actions. **Wager** Points removed from EL before rolling. Added back to result if roll succeeds.
